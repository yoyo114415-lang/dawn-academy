## 🌟 遊戲介紹

《破曉學園》是一款基於純前端技術開發的 2D 校園 RPG 探索網頁遊戲。玩家將化身為破曉學園的學生，透過沉浸式的第一人稱視角與多線性抉擇，體驗並面對校園中可能遭遇的人際衝突與言語排擠。

本遊戲旨在引導受凌或目睹霸凌的學童：
1. **覺察身心警訊**：理解人際衝突帶來的心理壓力，並透過「4-6 深呼吸減壓小遊戲」學習自我調節。
2. **正向因應技巧**：在多樣的情境選項中，思考何為健康堅定的邊界維護，而非以暴制暴或過度隱忍。
3. **建立求助信任**：認識校園內外的支持系統（導師、輔導室、生輔組長、家長與防霸凌專線）。
4. **全方位心理指標評估**：遊戲結算時生成「五維心靈成長雷達圖」，清楚對比冒險歷程中的心靈蛻變。

## 🎮 操作指引

### 電腦鍵盤
* **移動**：`W` / `A` / `S` / `D` 或 `↑` / `←` / `↓` / `→` 方向鍵
* **互動 / 對話推進**：靠近發光物件、門口或人物時按下 `E` 鍵或 `空白鍵`
* **抉擇選項**：點擊畫面上選項按鈕，或按下數字鍵 `1`、`2`、`3`
* **即時檢視**：點擊頂部狀態列 🏆 獎盃可隨時預覽五維心靈成長雷達圖

### 行動裝置（手機 / 平板）
* 支援螢幕左下角虛擬方向鍵（D-Pad）與右下角「互動」按鈕。
* 支援流暢觸控點擊對話與選項。

## 📊 五維心靈成長指標

結算雷達圖採正五角形對比模型（初始基準 vs 冒險蛻變）：
* **放鬆度（原壓力值）**：$100 - \text{壓力值}$（壓力過高會觸發深呼吸平復小遊戲）
* **同儕關係值**：人際支持與友善連結
* **勇氣值**：面對困難的主動面對意志
* **安全感**：對學校環境與師長制度的信任程度
* **自我肯定**：建立自我價值，不受負面言語貶低打擊

## 🛡️ 資安與技術安全宣言（Zero-Risk Policy）

1. **100% 純靜態前端**：不需任何後端伺服器或資料庫，使用純原生 JavaScript（Vanilla JS）、HTML5 Canvas 與 CSS3 開發。
2. **零個資蒐集**：遊戲全程不蒐集、不記錄任何玩家姓名、學號、帳號或個人機敏資料，落實資料最小化原則。
3. **零外部依賴與無毒保證**：
   * 音效全數由 Web Audio API 即時頻率合成（無外部音檔或惡意腳本）。
   * 無任何第三方追蹤代碼、廣告外掛或外部 CDN。
   * 遊戲存檔僅儲存於玩家本機瀏覽器 `localStorage`，隨時可一鍵清除。
